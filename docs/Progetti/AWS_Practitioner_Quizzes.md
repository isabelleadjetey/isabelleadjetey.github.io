## Quiz Giorno 1: Cloud Concepts & Economics (Dominio 1)

**Domanda 1**
Un'azienda ha bisogno di testare un nuovo applicativo. Invece di attendere tre settimane per l'acquisto e l'installazione di un server fisico nel proprio data center, utilizza AWS per avviare un server virtuale in soli 3 minuti. 
Quale vantaggio del Cloud AWS descrive meglio questo scenario?
*   A) Elasticity (Elasticità)
*   B) Agility (Agilità)
*   C) High Availability (Alta Disponibilità)
*   D) Pay-as-you-go pricing

**Domanda 2**
Quale concetto economico descrive la differenza tra l'acquistare l'infrastruttura IT fisicamente in anticipo (On-Premise) rispetto al pagare solo per le risorse computazionali nel momento in cui vengono utilizzate nel Cloud?
*   A) Passare da OpEx (Operational Expenditure) a CapEx (Capital Expenditure)
*   B) Passare da CapEx (Capital Expenditure) a OpEx (Operational Expenditure)
*   C) Riduzione del TCO (Total Cost of Ownership)
*   D) Economy of Scale (Economia di scala)

**Domanda 3**
Un sito di e-commerce subisce un enorme picco di traffico durante il Black Friday, per poi tornare a livelli normali il lunedì successivo. Quale caratteristica del Cloud AWS permette al sistema di aggiungere automaticamente server durante il picco e spegnerli quando non servono più per risparmiare sui costi?
*   A) Reliability (Affidabilità)
*   B) Scalability (Scalabilità)
*   C) Elasticity (Elasticità)
*   D) Fault Tolerance (Tolleranza ai guasti)

**Domanda 4**
Quale dei seguenti è un fattore che contribuisce ad abbassare il **TCO (Total Cost of Ownership)** quando un'azienda migra dal proprio Data Center verso il Cloud AWS?
*   A) Dover pagare in anticipo per riservare i server nel Cloud.
*   B) Non dover più pagare i costi per l'energia elettrica e il raffreddamento dei server fisici.
*   C) Affidarsi completamente ad AWS per la sicurezza dei dati dei clienti.
*   D) Assumere più sviluppatori per gestire le macchine virtuali.
