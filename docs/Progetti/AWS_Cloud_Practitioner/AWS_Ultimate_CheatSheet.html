DOMINIO 1: Cloud Concepts

1.1 I 6 Vantaggi del Cloud Computing

  • Trade capital expense for variable expense: Paghi solo per ciò che consumi (OpEx) invece di investire in anticipo (CapEx).
  • Benefit from massive economies of scale: Prezzi più bassi grazie all'utilizzo condiviso da centinaia di migliaia di clienti.
  • Stop guessing capacity: Ridimensiona dinamicamente invece di pagare per capacità inattiva o limitare le prestazioni.
  • Increase speed and agility: Le risorse sono a un clic di distanza (deploy da settimane a minuti).
  • Stop spending money running and maintaining data centers: Concentrati sui progetti che differenziano il tuo business.
  • Go global in minutes: Distribuisci le app in tutto il mondo in più Regioni con latenza minima.

  • IaaS (Infrastructure as a Service): Es. EC2. Hardware virtuale, tu gestisci OS e patch. Alta flessibilità.
  • PaaS (Platform as a Service): Es. Elastic Beanstalk. Tu scrivi il codice, AWS gestisce l'infrastruttura sottostante.
  • SaaS (Software as a Service): Es. Amazon WorkMail, Rekognition. Software gestito interamente dal fornitore.
  • FaaS (Serverless): Es. Lambda. Esegui codice a evento, paghi al millisecondo, zero server da gestire.

1.3 AWS Cloud Adoption Framework (CAF) e Migrazione

  • CAF (6 Prospettive): Business, People, Governance (prospettive Business) / Platform, Security, Operations (prospettive Tecniche).
  • Le 6 R della Migrazione: Rehost (Lift & Shift), Replatform (Lift, tinker and shift), Refactor/Rearchitect (Riscrivi nativo cloud), Repurchase (Passa a SaaS), Retain (Non spostare), Retire (Spegni).

DOMINIO 2: Security & Compliance

2.1 Shared Responsibility Model

graph TD subgraph Cliente ["Security IN the Cloud (Tuo Compito)"] A(Dati Utente / Crittografia) --> B(IAM / Password) B --> C(OS / Patch EC2 / Firewall VPC) end subgraph AWS ["Security OF the Cloud (Compito AWS)"] D(Hypervisor / Edge Locations) --> E(Rete Globale AWS) E --> F(Sicurezza Fisica Datacenter) end Cliente -.-> AWS
  • Security OF the Cloud (AWS): Sicurezza Fisica (Hardware, Datacenter, Rete globale, Infrastruttura fisica).
  • Security IN the Cloud (Cliente): Sicurezza Logica (Dati, Password IAM, Firewall VPC, Patch OS, Crittografia).

2.2 Servizi di Sicurezza e Identità

  • AWS IAM: Gestione globale utenti, gruppi, ruoli (assunti da risorse o identità esterne) e policy. Best practice: MFA obbligatoria e Principio del privilegio minimo.
  • AWS IAM Identity Center (ex SSO): Login singolo (SSO) per molti account AWS aziendali.
  • Amazon Cognito: Gestione identità per le tue applicazioni (registrazione/accesso utenti web e mobile).
  • AWS WAF (Web Application Firewall): Ferma attacchi hacker web comuni (SQL injection, XSS) al livello 7 (HTTP/HTTPS).
  • AWS Shield: Blocca attacchi DDoS. Lo Standard è gratis ed automatico, l'Advanced è a pagamento con supporto 24/7.
  • AWS KMS & CloudHSM: Gestione chiavi di crittografia (KMS centralizzato, CloudHSM hardware dedicato conforme a FIPS 140-2 Livello 3).
  • Amazon Macie: Usa il Machine Learning per scovare e proteggere dati sensibili (PII, carte di credito) nei bucket S3.
  • Amazon GuardDuty: Rilevamento minacce intelligente basato sui log continui (CloudTrail, VPC Flow Logs, DNS).
  • Amazon Inspector: Valutazione automatizzata per vulnerabilità software (CVE) e configurazioni errate su EC2 e container.
  • AWS Artifact: Portale centrale per scaricare certificazioni legali/compliance di AWS (ISO, SOC, PCI) e accordi legali.

DOMINIO 3: Technology and Services

3.1 Infrastruttura Globale

  • Region: Area geografica fisica (es. eu-south-1). Composta da minimo 2 Availability Zone (AZ).
  • Availability Zone (AZ): Uno o più data center fisici interconnessi in una Regione. Elevata ridondanza e isolamento dai guasti.
  • Edge Location: Endpoint globali per CloudFront (CDN) per caching veloce vicini agli utenti finali.

3.2 Calcolo (Compute)

  • Amazon EC2 (Elastic Compute Cloud): Server virtuali (IaaS).
  • AWS Lambda: Elaborazione Serverless. Esegue il codice a eventi, paghi in base ai millisecondi di calcolo.
  • Amazon ECS / EKS: Orchestrazione Container (ECS per Docker, EKS per Kubernetes).
  • AWS Fargate: Motore serverless per Container (non devi gestire le istanze EC2 sottostanti).
  • AWS Elastic Beanstalk: PaaS per deploy e scalabilità automatica (tu carichi il codice, AWS gestisce capacità, bilanciamento, ecc.).
  • AWS Outposts: Rack fisico AWS installato nel tuo datacenter locale (Hybrid Cloud nativo).

3.3 Archiviazione (Storage)

  • Amazon S3 (Simple Storage Service): Object storage (salvataggio a livello di bucket). Classi: Standard, IA (Infrequent Access), Glacier (Archiviazione a lungo termine a basso costo).
  • Amazon EBS (Elastic Block Store): Block storage. Disco virtuale (Volume) collegato a singola EC2 (stessa AZ). I dati sopravvivono allo spegnimento.
  • Amazon EFS (Elastic File System): File system condiviso di rete per istanze EC2 Linux (multi-AZ).
  • AWS Storage Gateway: Gateway cloud ibrido (cache locale su on-premises, dati backuppati e accessibili su S3).
  • AWS Snow Family: Dispositivi per migrazione offline (Snowcone, Snowball, Snowmobile) bypassando internet (petabytes di dati via posta).

3.4 Database

  • Amazon RDS: Database relazionale (SQL) gestito (motori: MySQL, PostgreSQL, Oracle, MariaDB, SQL Server).
  • Amazon Aurora: Database relazionale cloud-native di AWS (compatibile MySQL/Postgres), altissime performance e failover automatico.
  • Amazon DynamoDB: Database NoSQL, fully managed, latenza ms a singola cifra, Key-Value, scala all'infinito.
  • Amazon Redshift: Data Warehouse (OLAP) per Analytics e Business Intelligence su scala di petabyte.
  • Amazon ElastiCache: In-memory caching (Redis/Memcached) usato per velocizzare i DB alleviando i carichi di lettura.

3.5 Networking & Content Delivery

  • Amazon VPC (Virtual Private Cloud): Rete privata virtuale logicamente isolata dove lanciare le tue risorse.
  • Amazon Route 53: Servizio DNS gestito e scalabile, controlla il traffico a livello globale.
  • Amazon CloudFront: CDN globale, distribuisce risorse statiche e dinamiche tramite Edge Locations in tutto il mondo a bassissima latenza.
  • AWS Direct Connect: Connessione fibra dedicata e privata ufficio-AWS (più sicura, affidabile e con throughput costante rispetto a VPN).
  • Elastic Load Balancing (ELB): Bilanciatore del carico. Distribuisce il traffico in entrata su più target (es. Auto Scaling group di EC2).

3.6 Gestione, Analisi e Integrazione

  • Amazon CloudWatch: Monitoraggio delle performance. Raccoglie metriche, imposta allarmi (alarms) e log.
  • AWS CloudTrail: Auditing/Governance. Registra le chiamate API ("chi ha fatto cosa, e quando?").
  • AWS Auto Scaling: Aggiunge/rimuove istanze EC2 automaticamente in base al carico per garantire Elasticity e High Availability.
  • AWS CloudFormation: Infrastructure as Code (IaC). Usa template dichiarativi (JSON/YAML) per automatizzare la creazione di infrastrutture.
  • Amazon SNS & SQS: Servizi di integrazione. SNS per notifiche push (Pub/Sub), SQS per code di messaggi (Disaccoppiamento/Decoupling delle applicazioni).

DOMINIO 4: Billing, Pricing & Support

4.1 Modelli di Prezzo EC2

  • On-Demand: Nessun impegno a lungo termine, paghi al secondo/ora. Flessibile ma più costoso.
  • Reserved Instances (RI) / Savings Plans: Impegno di 1-3 anni per carichi di lavoro stabili (sconti fino a -72%).
  • Spot Instances: Capacità in eccesso, super economica (Fino a -90%), ma AWS può interromperla con 2 minuti di preavviso (ideale per batch/elaborazioni tolleranti ai guasti).
  • Dedicated Hosts: Server fisici dedicati interamente a te (usati spesso per licenze software legacy per socket/core).

4.2 Strumenti per Gestione Costi e Governance

  • AWS Pricing Calculator: Stima i costi dell'architettura prima di lanciare effettivamente le risorse.
  • AWS Cost Explorer: Strumento grafico per analizzare i costi storici (uso dei mesi precedenti) e prevedere l'utilizzo futuro (fino a 12 mesi).
  • AWS Budgets: Imposta limiti di spesa e ricevi allarmi personalizzati se i costi superano la soglia o le previsioni.
  • AWS Organizations: Gestione di più account da un nodo master, abilita la Fatturazione Consolidata e garantisce sconti sui volumi aggregati.
  • AWS Trusted Advisor: Analizza l'account per best practice su 5 pilastri (Ottimizzazione Costi, Sicurezza, Performance, Fault Tolerance, Limiti Servizio).

4.3 Piani di Supporto (Support Plans)

  • Basic: Gratis per tutti, supporto tecnico assente, supporto fatturazione/account, controlli essenziali Trusted Advisor.
  • Developer: Supporto tecnico via email in orario ufficio (per dev/test).
  • Business: Chat/Telefono 24/7 (per workload in produzione). Accesso totale a tutti i controlli Trusted Advisor.
  • Enterprise (On-Ramp / Enterprise): Massima priorità, risposta in meno di 15 min per sistemi critici. Include un TAM (Technical Account Manager) dedicato.
