L'Enciclopedia Definitiva - 100% dei Servizi dell'Esame

1. Compute (Calcolo)

  • Amazon EC2: Server virtuale (IaaS). Gestione totale dell'OS.
  • AWS Lambda: Serverless / FaaS. Esegui codice a evento, paghi al millisecondo.
  • AWS Elastic Beanstalk: PaaS. Carichi il codice web, AWS crea l'infrastruttura in automatico.
  • Amazon ECS: Orchestrazione Container proprietaria AWS (Docker).
  • Amazon EKS: Orchestrazione Container standard open-source (Kubernetes).
  • AWS Fargate: Motore Serverless per far girare i container senza gestire le istanze EC2 sottostanti.
  • Amazon Lightsail: Il server virtuale "per principianti" (VPS preconfigurata a costo fisso).
  • AWS Outposts: Server fisici AWS installati nel tuo datacenter (Cloud Ibrido).
  • AWS Batch: Per elaborazioni di dati massicce in parallelo.

2. Storage

  • Amazon S3: Object storage. Dati piatti, immagini, log, siti web statici. (Classe Standard = default).
  • S3 Standard-IA: Infrequent Access. Accesso immediato ma file letti raramente (più economico dello Standard).
  • S3 One Zone-IA: Dati in una sola AZ. Più economico ma meno ridondante.
  • S3 Glacier Flexible Retrieval: Archiviazione. Recupero da minuti a ore.
  • S3 Glacier Deep Archive: Archiviazione a lungo termine a costo infimo. Recupero in 12 ore.
  • S3 Intelligent-Tiering: Sposta i dati tra classi in automatico usando l'AI per risparmiare.
  • Amazon EBS: Block storage. L'hard disk collegato a 1 singola istanza EC2.
  • Amazon EFS: File storage (NFS). Disco condiviso a cui accedono molte istanze Linux contemporaneamente.
  • Amazon FSx: File system nativo ad alte prestazioni per Windows o per HPC (Lustre).
  • AWS Storage Gateway: Ponte ibrido. Collega i server locali allo storage in cloud (S3).
  • AWS Snow Family: Valigie fisiche per spostare enormi dati (Snowcone, Snowball Edge, Snowmobile).

3. Database

  • Amazon RDS: Database relazionale (SQL). AWS gestisce backup e patch.
  • Amazon Aurora: Versione "premium" di RDS proprietaria AWS, ultra veloce.
  • Amazon DynamoDB: Database NoSQL (Key-Value). Serverless, latenza bassissima, scala all'infinito.
  • Amazon DocumentDB: Database NoSQL per documenti (Compatibile MongoDB).
  • Amazon Redshift: Data Warehouse. Big Data e Analytics (es. Data mining storico).
  • Amazon Neptune: Graph Database (usato per social network, raccomandazioni, engine relazionali complessi).
  • Amazon QLDB: Database a registro (Ledger). Criptograficamente immutabile (es. per transazioni finanziarie).
  • Amazon ElastiCache: Caching in-memory (Redis, Memcached) per velocizzare letture estreme.

4. Networking & Content Delivery

  • Amazon VPC: Rete virtuale privata isolata (Subnet, Gateway, Route tables).
  • Amazon Route 53: Servizio DNS. (Route 53 = DNS sulla porta 53).
  • Amazon CloudFront: CDN (Content Delivery Network). Usa Edge Locations per latenza nulla globalmente.
  • AWS Direct Connect: Cavo in fibra ottica fisico e dedicato tra l'ufficio e AWS. Non passa su internet.
  • AWS VPN: Connessione sicura verso il VPC usando l'Internet pubblico.
  • AWS Transit Gateway: L'Hub centrale di rete. Connette migliaia di VPC e reti on-premise insieme.
  • AWS Global Accelerator: Riduce la latenza indirizzando il traffico sul backbone privato di AWS invece che su internet pubblico.
  • Amazon API Gateway: Crea e protegge API (spesso di fronte alle funzioni Lambda).

5. Security, Identity & Compliance

  • AWS IAM: Gestione utenti, gruppi, ruoli e policy.
  • AWS IAM Identity Center (ex SSO): Login singolo per accedere a molteplici account AWS.
  • AWS WAF: Web Application Firewall. Protegge le app (Layer 7) da SQL injection/XSS.
  • AWS Shield: Protezione DDoS (Layer 3/4). Lo Standard è automatico e gratuito.
  • AWS KMS: Key Management Service. Crea e gestisce chiavi crittografiche.
  • AWS CloudHSM: Crittografia basata su hardware fisico dedicato.
  • AWS Secrets Manager: Salva e ruota in automatico le password del database in modo sicuro.
  • Amazon Macie: Intelligenza artificiale per scovare dati sensibili (carte di credito) nascosti in S3.
  • Amazon GuardDuty: "La guardia giurata". Analizza log per rilevare minacce in background.
  • Amazon Inspector: Scansiona server EC2 e container per vulnerabilità software.
  • AWS Security Hub: Il cruscotto centrale per gli avvisi di GuardDuty, Macie e Inspector.
  • AWS Artifact: Portale per scaricare report legali di conformità di AWS (ISO, SOC).
  • Amazon Cognito: Gestisce registrazione e login (Identity Pool) per utenti della tua Web App.

6. Management & Governance

  • Amazon CloudWatch: Monitoraggio Performance (CPU, RAM, allarmi).
  • AWS CloudTrail: Auditing di Sicurezza. Registra API calls (Chi ha fatto cosa?).
  • AWS Trusted Advisor: Controlla costi, sicurezza, fault tolerance, performance, service limits.
  • AWS Config: Registra storico modifiche (es. "Chi ha cambiato questa regola del firewall 3 giorni fa?").
  • AWS CloudFormation: Infrastructure as Code (YAML/JSON).
  • AWS Systems Manager (SSM): Patching e gestione automatizzata di intere flotte di server EC2.
  • AWS Control Tower: Governance e gestione rapida per decine di account aziendali insieme.

7. Analytics & Machine Learning

  • Amazon Athena: Fai query SQL sui file parcheggiati su S3 (senza creare server DB).
  • Amazon Kinesis: Elaborazione e ingestione dati in Real-Time Streaming (es. clickstream live).
  • Amazon EMR: Big Data framework managed (Hadoop, Spark).
  • Amazon QuickSight: Business Intelligence (Dashboard interattive per manager).
  • AWS Glue: Servizio ETL (Extract, Transform, Load) per preparare i dati.
  • Amazon SageMaker: Sviluppare e allenare modelli Machine Learning.
  • Amazon Rekognition: Riconoscimento immagini e video (volti, oggetti).
  • Amazon Polly: Da Testo a Voce (Text-to-Speech).
  • Amazon Transcribe: Da Voce a Testo (Speech-to-Text).
  • Amazon Comprehend: NLP. Analisi del testo per capire il "sentimento" (Positivo, Negativo).
  • Amazon Translate: Traduzione automatica tra decine di lingue.

8. Application Integration

  • Amazon SNS: Simple Notification Service. Spedisce messaggi a pioggia (Pub/Sub) via email o sms.
  • Amazon SQS: Simple Queue Service. Code di messaggi per "disaccoppiare" le app.
  • AWS Step Functions: Workflow visivo a cascata (gestisce logiche di errore tra le Lambda).

9. Billing, Pricing & Support

  • AWS Organizations: Fatturazione consolidata (sconti volume) + SCP (Blocca i permessi centralmente).
  • AWS Cost Explorer: Analisi grafiche storiche + Previsioni.
  • AWS Budgets: Alert istantanei al superamento spesa.
  • AWS Pricing Calculator: Simulazioni preventive dei costi.
  • Support Plans:
    • Basic: Nessun supporto tecnico.
    • Developer: Email business hours.
    • Business: Chat 24/7. Trusted Advisor completo.
    • Enterprise: Supporto critico 15-min. TAM (Technical Account Manager).

10. Global Infrastructure & Frameworks

  • Globale: IAM, Route 53, CloudFront, WAF.
  • Regionale: S3, EC2, Lambda, DynamoDB, RDS.
  • Well-Architected Framework: 1) Eccellenza Operativa 2) Sicurezza 3) Affidabilità 4) Efficienza Prestazionale 5) Ottimizzazione Costi 6) Sostenibilità.
