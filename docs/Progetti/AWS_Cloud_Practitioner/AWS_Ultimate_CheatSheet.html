DOMINIO 1: Cloud Concepts

1.1 Definizioni Fondamentali

  • Cloud Computing: Fornitura on-demand di risorse IT tramite Internet con prezzi pay-as-you-go.
  • CapEx vs OpEx: Il Cloud trasforma spese in conto capitale (hardware) in spese operative (affitto al secondo).
  • High Availability: Sistema funziona senza interruzioni (es. server sparsi su più Availability Zones).
  • Fault Tolerance: Capacità di continuare a funzionare anche se un componente si rompe.
  • Scalability: Scalare Verticalmente (Scale Up = CPU/RAM) o Orizzontalmente (Scale Out = più server).
  • Elasticity: Scalare in automatico sia verso l'alto che verso il basso a seconda della domanda (Auto Scaling).

1.2 I Modelli di Servizio

  • IaaS (Infrastructure as a Service): Es. EC2. Hardware virtuale, tu gestisci OS e patch.
  • PaaS (Platform as a Service): Es. Elastic Beanstalk. Tu scrivi il codice, AWS gestisce l'infrastruttura.
  • SaaS (Software as a Service): Es. Zoom. Software gestito interamente dal fornitore.
  • FaaS (Serverless): Es. Lambda. Esegui codice a evento, paghi al millisecondo, zero server da gestire.

1.3 AWS Cloud Adoption Framework (CAF) e Migrazione

  • CAF (6 Prospettive): Business, People, Governance (Business) / Platform, Security, Operations (Tecniche).
  • Le 6 R della Migrazione: Rehost (Lift & Shift), Replatform (Modifica leggera), Refactor (Riscrivi nativo cloud), Repurchase (Passa a SaaS), Retain (Non spostare), Retire (Spegni).

DOMINIO 2: Security & Compliance

2.1 Shared Responsibility Model

  • Security OF the Cloud (AWS): Sicurezza Fisica (Hardware, Datacenter, Rete globale).
  • Security IN the Cloud (Cliente): Sicurezza Logica (Dati, Password IAM, Firewall VPC, Patch OS).

2.2 Servizi di Sicurezza

  • AWS IAM: Gestione utenti, gruppi, ruoli (permessi per EC2) e policy. MFA obbligatoria per Root.
  • AWS IAM Identity Center: Login singolo per molti account AWS aziendali.
  • AWS WAF: Ferma attacchi hacker (SQL injection, XSS) - Layer 7.
  • AWS Shield: Blocca attacchi DDoS (Layer 3/4). Lo Standard è gratis.
  • AWS KMS & CloudHSM: Generazione chiavi di crittografia (CloudHSM usa hardware fisico tuo).
  • Amazon Macie: Intelligenza Artificiale per scovare carte di credito o PII su Amazon S3.
  • Amazon GuardDuty: Rilevamento minacce intelligente basato sui log.
  • Amazon Inspector: Scansiona server EC2 per vulnerabilità software (CVE).
  • AWS Artifact: Portale PDF per scaricare certificazioni legali/compliance di AWS (ISO, SOC).

DOMINIO 3: Technology and Services

3.1 Architettura e Globale vs Regionale

  • Region: Cluster geografico (es. eu-south-1). Minimo 3 Availability Zone (AZ).
  • Edge Location: Mini-datacenter periferici per CloudFront.
  • Globali: IAM, Route 53, CloudFront, WAF.
  • Regionali: EC2, S3 (nome globale ma salvataggio regionale), RDS, VPC.

3.2 Compute (Calcolo)

  • Amazon EC2: Server virtuale. Lambda: Serverless FaaS.
  • Amazon ECS / EKS: Orchestrazione Container (Docker / Kubernetes).
  • AWS Fargate: Motore serverless per Container (non gestisci le istanze sottostanti).
  • Amazon Lightsail: VPS facile a costo fisso per principianti.
  • AWS Outposts: Hardware AWS fisico installato nel tuo datacenter (Hybrid).

3.3 Storage

  • Amazon S3: Object storage. Classi: Standard, IA (Infrequent Access), Glacier (Archiviazione lenta), Intelligent-Tiering.
  • Amazon EBS: Block storage. L'hard disk collegato a singola EC2.
  • Amazon EFS: File system condiviso per N istanze Linux.
  • Amazon FSx: File system nativo Windows/HPC.
  • AWS Storage Gateway: Cloud Ibrido (cache locale, dati su S3).
  • Snow Family: Valigie fisiche per migrazione offline (Snowcone, Snowball, Snowmobile).

3.4 Database

  • Amazon RDS: Database SQL gestito. Aurora: Versione super veloce proprietaria AWS.
  • Amazon DynamoDB: Database NoSQL. Latenza ms, scala all'infinito.
  • Amazon Redshift: Data Warehouse per Analytics storici.
  • Amazon ElastiCache: In-memory caching (Redis/Memcached).

3.5 Networking & Content Delivery

  • Amazon VPC: Rete privata virtuale.
  • Amazon Route 53: Servizio DNS.
  • Amazon CloudFront: CDN globale.
  • AWS Direct Connect: Cavo fisico privato ufficio-AWS (no Internet).
  • AWS Transit Gateway: Hub centrale per decine di VPC e reti on-premise.

3.6 Governance & Analytics

  • CloudWatch: Performance (CPU, Allarmi).
  • CloudTrail: Sicurezza/Auditing (Chi ha fatto cosa sulle API?).
  • Trusted Advisor: Valuta Costi, Sicurezza, Performance, Fault Tolerance, Limiti.
  • CloudFormation: Infrastructure as Code (YAML).
  • Amazon Athena: Query SQL dirette su file in S3.
  • Machine Learning: SageMaker (AI models), Rekognition (Immagini), Polly (Testo a voce).

DOMINIO 4: Billing, Pricing & Support

4.1 Modelli di Prezzo

  • On-Demand: Nessun impegno, paghi al secondo (Costoso).
  • Reserved / Savings Plans: Impegno di 1-3 anni (Fino a -72%).
  • Spot Instances: Server in eccedenza, AWS te li può spegnere con 2 minuti di preavviso (Fino a -90%).

4.2 Strumenti per i Costi

  • AWS Organizations: Fattura unica consolidata, sconti volume, SCP.
  • AWS Pricing Calculator: Preventivi online prima di comprare.
  • AWS Cost Explorer: Grafici storici e previsioni future.
  • AWS Budgets: Allarmi quando sfori il budget.

4.3 Support Plans

  • Basic: Gratis, no supporto tecnico, solo billing.
  • Developer: Email in orario ufficio.
  • Business: Chat/Telefono 24/7. Trusted Advisor completo.
  • Enterprise: TAM (Technical Account Manager) dedicato.
