Recap Missioni NSE 4

Laboratorio FortiGate - Sintesi dei concetti avanzati applicati

🛡️ Missione 1: Rete Guest Blindata Completata

Configurazione del traffico in uscita (Outbound) con restrizioni rigorose usando i Security Profiles.

NAT Overload (IP Pool)

Abbiamo sganciato l'IP di uscita da quello dell'interfaccia WAN, usando un Dynamic IP Pool per mappare molti host interni su un singolo IP pubblico dedicato agli ospiti.

Web Filtering vs App Control

Il Web Filter legge gli URL (es. facebook.com), mentre l'Application Control legge la firma del traffico (es. YouTube App). Entrambi sono necessari per una sicurezza a livello 7.

L'inganno del QUIC

Applicazioni come YouTube aggirano l'ispezione standard usando il protocollo UDP (QUIC). Forzando i servizi a HTTP/HTTPS (TCP) si costringe il browser sotto la lente del firewall.

HSTS (Strict Transport Security)

Quando il FortiGate intercetta una connessione HTTPS di un sito ad alta sicurezza come YouTube, il browser va in blocco totale (no tasto "Advanced") per prevenire attacchi Man-in-the-Middle.

🌐 Missione 2: Pubblicare un Server In Corso

Configurazione del traffico in ingresso (Inbound) esponendo un servizio privato a Internet.

Destination NAT (Virtual IP)

Al contrario del Source NAT, il VIP prende il traffico che arriva dall'esterno verso un IP Pubblico e lo "gira" in modo trasparente verso l'IP privato del server nella LAN/DMZ.

Il NAT Spento nella Policy

Errore classico: accendere il NAT nella policy Inbound. Non va fatto! Il VIP traduce già la destinazione; se accendessimo il NAT, maschereremmo l'IP del cliente e il server vedrebbe tutto il traffico arrivare dal Firewall.

🧠 Pillole di Architettura

CCNA vs NSE 4

In Cisco (L3/L4) la sicurezza si fa bloccando IP e porte con le ACL. Nel FortiGate (NGFW L7) si usano gli Address Objects e si ispeziona il contenuto del pacchetto, indipendentemente dalla porta, con le Policy Stateful.

Il Problema del Double NAT

In un lab casalingo, il FortiGate e il router dell'operatore fanno NAT due volte. In un'azienda reale, il router del provider è in Bridge Mode e il FortiGate riceve direttamente l'IP Pubblico (Single NAT).
