Mastering FortiGate NSE 4

Il percorso di laboratorio definitivo per diventare pienamente operativi

Questa guida copre il 100% degli argomenti pratici richiesti per la certificazione NSE 4 (FCP FortiOS Administrator) e per gestire in autonomia un firewall aziendale. È divisa in quattro macro-aree logiche. Esegui questi test in sequenza sulla tua VM.

💡 Novità: Ti sei bloccato su un laboratorio? Ho preparato la Guida alle Soluzioni Step-by-Step con tutti i passaggi da seguire nella GUI del FortiGate per risolvere i laboratori 1-7!

🛡️ Modulo 1: Fondamenti e Sicurezza Iniziale

1. System & Admin Setup

System
  • System Settings: Imposta Hostname, NTP (sincronizzazione orario vitale per i certificati), e Idle Timeout.
  • Admin Profiles: Crea un profilo "Read-Only" e un utente associato. Verifica cosa può (e non può) fare.
  • Admin Access: Usa i Trusted Hosts sull'utente admin per limitare il login a uno specifico IP (es. il tuo PC). Disabilita PING sulla porta WAN.
  • Configuration Backup: Esegui un backup cifrato (con password) e prova a ripristinarlo.

2. Network Base & DHCP

Network
  • Interfacce: Configura WAN (DHCP o Statica) e LAN (Statica, es. 10.0.0.254/24). Aggiungi gli alias (es. "Rete_Uffici").
  • DHCP Server: Abilitato sulla LAN. Configura la DHCP Reservation (MAC Binding) per dare a un PC un IP fisso garantito tramite DHCP.
  • DNS: Configura i FortiGuard DNS. Imposta il FortiGate come DNS Server locale per la LAN.

3. Policy & Address Objects

Firewall
  • Address & Groups: Crea subnet objects, FQDN objects (es. `*.microsoft.com`) e raggruppali in un Address Group.
  • Services: Crea un servizio custom TCP con una porta non standard (es. 8443).
  • Policy Sequence: Crea regole granulari e posizionale in cima. Verifica il concetto di Fall-through (se una regola non matcha, passa alla successiva).
  • Schedules: Crea un orario "Pausa Pranzo" (Recurring) o un evento specifico (One-time) e applicalo a una policy.

🔒 Modulo 2: NGFW, Autenticazione e NAT

4. Network Address Translation (NAT)

NAT
  • Source NAT (SNAT): Usa "Outgoing Interface Address" per mascherare la LAN. Poi testa un "Dynamic IP Pool" per mascherare il traffico usando un IP pubblico diverso da quello dell'interfaccia.
  • Central SNAT: (Avanzato) Abilitalo in Settings. Separa la tabella NAT dalle policy di sicurezza.
  • Destination NAT (VIP): Crea un Virtual IP per esporre un server web interno sulla porta WAN 80. Fai Port Forwarding (es. dalla porta esterna 8080 alla interna 80).

5. User Authentication (Captive Portal)

Identity
  • Local Users: Crea utenti locali e inseriscili in un User Group.
  • Active Authentication: Modifica una policy LAN-WAN aggiungendo lo User Group in "Source". Prova a navigare dal client e verifica che appaia la schermata di login (Captive Portal).
  • FSSO (Concetto): Documentati su Fortinet Single Sign-On per autenticare gli utenti in modo trasparente tramite Active Directory senza che debbano inserire password.

6. Certificati e SSL Inspection

Crypto
  • Certificate Inspection: Analizza solo l'SNI (Server Name Indication) del traffico HTTPS (metodo base, nessun errore sui client).
  • Deep Packet Inspection (DPI): Il FortiGate decifra tutto il traffico HTTPS. Installa il certificato Fortinet_CA_SSL sul tuo client (Lubuntu/Windows) per non avere errori di sicurezza nei browser.
  • Exemptions: Metti in esclusione i domini bancari e sanitari dalla Deep Inspection per motivi di privacy.

7. Security Profiles (UTM)

UTM
  • Antivirus: Blocca virus basati su firme. Prova a scaricare il file di test *EICAR*.
  • Web Filtering: Blocca "Adult" e "Gambling" tramite i server FortiGuard. Metti un sito in "Allow" tramite l'URL Filter locale. Usa i "Warning" per avvisare l'utente.
  • Application Control: Blocca YouTube o BitTorrent. Noterai che Application Control se ne frega delle porte usate (blocca anche se mascherato su porta 443).
  • IPS (Intrusion Prevention): Blocca tentativi di brute force e vulnerabilità note.

🌐 Modulo 3: Infrastruttura di Rete Avanzata

8. Routing Avanzato

Routing
  • Static Routing & ECMP: Aggiungi due rotte statiche di default con stessa "Distance". Il firewall farà Equal Cost Multi-Path (bilanciamento).
  • Policy Routing: Crea una Policy Route per forzare tutto il traffico di uno specifico PC su una porta WAN secondaria, ignorando la tabella di routing classica.
  • Routing Monitor: Usa la GUI per capire esattamente quale rotta è attiva (FIB).

9. SD-WAN (Software-Defined WAN)

SD-WAN
  • Zone: Inserisci le tue due porte WAN in una zona SD-WAN virtuale (ATTENZIONE: non puoi farlo se le porte sono in uso da policy!).
  • Performance SLA: Imposta un ping costante verso 8.8.8.8. SD-WAN calcolerà Packet Loss, Latency e Jitter dei tuoi link.
  • SD-WAN Rules: Crea una regola "Maximize Bandwidth" o "Lowest Cost" per far scegliere dinamicamente al firewall il link migliore.

10. VPN Site-to-Site (IPsec)

VPN
  • Custom IPsec: Crea un tunnel manuale tra due siti. Fai attenzione alla Fase 1 (IKE) e Fase 2 (IPsec ESP). Fai combaciare le Pre-shared key.
  • Routing e Policy: Ricorda che una VPN IPsec Route-Based crea un'interfaccia virtuale. Devi creare rotte verso la subnet remota usando il tunnel IPsec come gateway, e fare policy bidirezionali.

11. SSL VPN (Remote Access)

VPN
  • VPN Settings: Definisci il range di IP da assegnare ai dipendenti remoti (es. 10.212.134.10-100).
  • Web Portal: Configura i bookmark per RDP o SSH accessibili via Browser senza installare nulla.
  • Tunnel Mode: Usa FortiClient. Crea una regola che permetta all'interfaccia ssl.root di accedere alla LAN interna.

🛠️ Modulo 4: Architettura e Troubleshooting

12. VDOM (Virtual Domains) e Layer 2

Architettura
  • VDOM: Abilita i Multi-VDOM. Crea un VDOM "Guest" completamente separato dalla rete aziendale "Root". Configura un inter-vdom link per farli comunicare tramite policy.
  • Transparent Mode: Configura un VDOM in modalità Layer 2 (senza indirizzi IP sulle porte). Funzionerà come uno switch invisibile che applica l'Antivirus a pacchetti di passaggio.

13. High Availability (HA)

Resilienza
  • Active-Passive: Unisci due FortiGate in Cluster. Usa una porta dedicata (Heartbeat). Spegni il Master e guarda i ping del client che si riprendono dopo 1-2 secondi mentre passa allo Slave.
  • Sync: Verifica la sincronizzazione delle configurazioni e delle sessioni attive.

14. Diagnostica e CLI (Fondamentale NSE4)

Troubleshooting
  • Impara a catturare i pacchetti al volo (come Wireshark) usando la CLI. Dal terminale prova: diag sniffer packet any 'host 8.8.8.8' 4 0 l
  • Usa il Debug Flow per capire perché un pacchetto viene scartato dal firewall: diag debug flow filter daddr 8.8.8.8
