CCNA 200-301

Ultimate Cheat Sheet

Master Cheat Sheet: CCNA 200-301 Ultimate

OBIETTIVO: Riferimento completo e definitivo per l'esame Cisco CCNA 200-301. Copre Device Management, L2, L3, Servizi, Sicurezza, Wireless, Automazione e Troubleshooting.

1. Device Management & Sicurezza Accessi

Navigazione e Modalità

  • enable: User EXEC → Privileged EXEC (#).
  • configure terminal: Privileged EXEC → Global Configuration ((config)#).
  • copy running-config startup-config: Salva in NVRAM.
  • write memory (o wr): Comando rapido per salvare.
  • erase startup-config seguito da reload: Ripristina alle impostazioni di fabbrica.

Sicurezza Base

  • enable secret [PASSWORD]: Password criptata (MD5) per l'accesso privilegiato (sostituisce enable password).
  • service password-encryption: Cripta debolmente (Type 7) le password in chiaro nel file di config.
  • line console 0 → password [PWD] → login: Protegge la porta console.
  • line vty 0 15 → transport input ssh → login local: Forza l'uso di SSH per il telnet virtuale e usa il database utenti locale.
  • username [NOME] privilege 15 secret [PWD]: Crea utente amministratore locale.

Configurazione SSH

  • ip domain-name [DOMINIO]: Pre-requisito per SSH.
  • crypto key generate rsa modulus 2048: Genera le chiavi per abilitare SSH v2.
  • ip ssh version 2: Forza l'uso di SSHv2 (più sicuro).

2. Layer 2: Switching, VLAN, STP e EtherChannel

VLAN e Trunking (802.1Q)

  • vlan [ID] → name [NAME]: Crea e rinomina una VLAN.
  • switchport mode access → switchport access vlan [ID]: Configura una porta verso un PC.
  • switchport voice vlan [ID]: Configura la VLAN per i telefoni IP.
  • switchport mode trunk: Imposta la porta come trunk.
  • switchport trunk encapsulation dot1q: Su alcuni switch vecchi è necessario prima del comando trunk.
  • switchport trunk native vlan [ID]: Cambia la VLAN nativa per ragioni di sicurezza (mitiga gli attacchi di hopping).
  • switchport trunk allowed vlan [LISTA]: Filtra le VLAN sul trunk (es. 10,20,30).

EtherChannel (LACP - 802.3ad)

  • interface range [INT_LIST] → channel-group [ID] mode [active|passive]: Configura LACP.
  • channel-group [ID] mode [desirable|auto]: Configura PAgP (proprietario Cisco).
  • channel-group [ID] mode on: EtherChannel statico (nessun protocollo).
  • interface port-channel [ID]: Entra nell'interfaccia logica per configurare il trunk/access.

Spanning Tree Protocol (STP)

  • spanning-tree mode rapid-pvst: Abilita RPVST+ (standard raccomandato CCNA).
  • spanning-tree vlan [ID] root primary: Forza lo switch a diventare Root Bridge abbassando la priorità.
  • spanning-tree vlan [ID] priority [VALORE]: Imposta manualmente la priorità (multipli di 4096).
  • spanning-tree portfast: Configura su porte access collegate a PC per bypassare gli stati di Listening e Learning (Subito FWD).
  • spanning-tree bpduguard enable: Da usare insieme a PortFast per disabilitare (err-disable) la porta se riceve BPDU.

3. Layer 3: Routing IPv4, IPv6 e OSPF

Routing IPv4 Base

  • ip route 0.0.0.0 0.0.0.0 [NEXT_HOP_IP o EXIT_INT]: Rotta statica di default.
  • ip route [RETE_DESTINAZIONE] [SUBNET_MASK] [NEXT_HOP_IP] [AD]: Rotta statica specifica. Aggiungendo un numero AD alla fine crei una Floating Static Route (backup).
  • Router-on-a-Stick: interface [INT].[VLAN_ID] → encapsulation dot1Q [VLAN_ID] → ip address [IP] [MASK].
  • interface vlan [ID] → ip address [IP] [MASK] → no shutdown: Configura una SVI (Switch Virtual Interface) per routing su Multilayer Switch.
  • ip routing: Abilita il routing IP sugli switch Layer 3.

Routing IPv6

  • ipv6 unicast-routing: Fondamentale! Abilita il routing IPv6 sul router.
  • ipv6 address [PREFIX::ID]/64: Assegna un indirizzo Global Unicast.
  • ipv6 address fe80::[ID] link-local: Assegna manualmente un indirizzo Link-Local.
  • ipv6 route ::/0 [NEXT_HOP_IPv6]: Rotta di default IPv6.

OSPFv2 (Single Area)

  • router ospf [PROCESS_ID]: Avvia il processo OSPF.
  • router-id [IP_FORMAT]: Assegna un ID manuale (es. 1.1.1.1).
  • network [RETE_IP] [WILDCARD_MASK] area [AREA_ID]: Dichiara le reti da includere nel processo OSPF.
  • passive-interface [INT]: Impedisce l'invio di pacchetti Hello su interfacce LAN per sicurezza (mantiene la rete nel database routing).
  • default-information originate: Inietta la rotta statica di default nel dominio OSPF.
  • auto-cost reference-bandwidth [Mbps]: Adeguamento del calcolo metrico per link veloci (es. gigabit o 10G).

4. Servizi IP: DHCP, NAT, NTP, CDP/LLDP

DHCP Server & Relay

  • ip dhcp excluded-address [START_IP] [END_IP]: Esclude IP dall'assegnazione automatica.
  • ip dhcp pool [NAME] → network [RETE] [MASK] → default-router [GW_IP] → dns-server [DNS_IP].
  • ip helper-address [DHCP_SERVER_IP]: Usato sulle interfacce Router (o SVI) per inoltrare le richieste broadcast DHCP verso server in un'altra subnet.

NAT (Network Address Translation)

  • Static NAT: ip nat inside source static [PRIVATE_IP] [PUBLIC_IP]
  • PAT (NAT Overload):
    • Crea ACL: access-list 1 permit [RETE_PRIVATA] [WILDCARD]
    • Attiva PAT: ip nat inside source list 1 interface [WAN_INT] overload
  • Non dimenticare di configurare le interfacce: ip nat inside (su LAN) e ip nat outside (su WAN).

Gestione e Discovery

  • NTP: ntp server [IP] imposta il router per sincronizzare l'orologio.
  • CDP (Proprietario Cisco): cdp run (globale), cdp enable (interfaccia).
  • LLDP (Standard IEEE): lldp run (globale), lldp transmit / lldp receive (interfaccia).
  • Syslog: logging host [IP_SYSLOG] → logging trap [LEVEL 0-7].

5. Security & Infrastructure Hardening

Access Control Lists (ACL)

  • Standard ACL (1-99): Filtrano SOLO in base all'IP di origine. Posizionale il più vicino possibile alla destinazione.
    access-list 10 permit [IP_ORIGINE] [WILDCARD]
  • Extended ACL (100-199): Filtrano su IP Origine, IP Destinazione e Porte (TCP/UDP). Posizionale il più vicino possibile all'origine.
    access-list 101 deny tcp host [IP_SRC] host [IP_DST] eq 80
    access-list 101 permit ip any any (Impedisce la Implicit Deny finale).
  • interface [INT] → ip access-group [ID] [in|out]: Applica l'ACL.

L2 Security (Port Security & DHCP Snooping)

  • Port Security:
    • switchport mode access (Richiesto prima di attivare)
    • switchport port-security (Attiva)
    • switchport port-security maximum [N] (Limite MAC)
    • switchport port-security mac-address sticky (Memorizza dinamicamente i MAC in config)
    • switchport port-security violation [shutdown | restrict | protect].
  • DHCP Snooping: Protegge contro Rogue DHCP server.
    • ip dhcp snooping → ip dhcp snooping vlan [ID].
    • interface [INT] (porta collegata al Server DHCP legittimo) → ip dhcp snooping trust.
  • Dynamic ARP Inspection (DAI): Dipende dal DHCP Snooping per fermare l'ARP Poisoning. ip arp inspection vlan [ID].

6. Wireless, QoS e FHRP

Wireless LAN (WLAN)

  • Architettura: WLC (Wireless LAN Controller) gestisce i LAP (Lightweight Access Point) usando tunnel CAPWAP.
  • Sicurezza Wireless: WPA2 usa AES, WPA3 usa SAE (Simultaneous Authentication of Equals). Enterprise richiede server RADIUS (802.1X).
  • WLC GUI: Per creare una WLAN serve un Profilo, associarlo a un'interfaccia WLC (VLAN), e configurare la sicurezza (es. PSK o 802.1x).

Quality of Service (QoS)

  • Classification: Identifica il tipo di traffico.
  • Marking: DSCP (L3) raccomandato. Es: EF (Expedited Forwarding = Voice), AF (Assured Forwarding = Video/Data). Cos (L2).
  • Queuing/Scheduling: CQ, PQ, WFQ, CBWFQ, LLQ (Low Latency Queuing = Migliore per la voce).

FHRP (First Hop Redundancy Protocol)

  • HSRP (Cisco Proprietary): standby [ID] ip [VIRTUAL_IP]. Router Active e Standby.
  • VRRP (Open Standard): Router Master e Backup.
  • GLBP (Cisco Proprietary): Offre bilanciamento del carico attivo (Load Balancing) tra i vari router (AVG/AVF).

7. Network Architecture, SDN & Automation

  • Spine-and-Leaf Architecture: Nessun collegamento tra Leaf o tra Spine. Tutti i Leaf sono connessi a tutti gli Spine (ottimizzato per traffico Est-Ovest tipico dei Datacenter).
  • Cisco DNA Center: Controller per reti Enterprise (SD-Access). Fornisce Intent-based Networking e Assurance. Usa API verso il nord (Applicazioni) e CLI/NETCONF/RESTCONF verso il sud (Apparati).
  • JSON (JavaScript Object Notation): Usa {} per oggetti (coppie chiave:valore) e [] per array. Tipicamente usato dalle API REST.
  • REST API:
    • GET (Leggere)
    • POST (Creare nuovo elemento)
    • PUT/PATCH (Aggiornare o modificare elemento esistente)
    • DELETE (Eliminare elemento)
  • Puppet / Chef / Ansible: Strumenti di Configuration Management. Ansible usa SSH e YAML (Agentless). Chef/Puppet usano Ruby e spesso richiedono Agent sugli switch.

8. Master Troubleshooting (T-Shoot)

Comando Cosa Mostra e a cosa Serve
show ip interface brief Stato L1/L2 (Status e Protocol), IP assegnati. Primo comando per capire se le porte sono UP/UP.
show interfaces [INT] Statistiche, Errori (CRC, Input/Output), MAC Address, Bandwidth e MTU.
show vlan brief Elenco VLAN e quali porte in modalità access vi appartengono (Non mostra i trunk!).
show interfaces trunk Quali porte sono Trunk, la VLAN nativa impostata, e le VLAN consentite sul link.
show ip route Tabella di routing L3. Mostra le rotte (C=Connected, S=Static, O=OSPF).
show ip ospf neighbor Mostra i vicini OSPF. Lo stato ideale per reti Ethernet broadcast è FULL/DR o FULL/BDR o FULL/DROTHER (se tra drother allora 2WAY).
show mac address-table Mostra le associazioni MAC-Porta (L2 forwarding table dello switch).
show etherchannel summary Stato del LACP/PAgP. Controlla che le porte fisiche abbiano il flag P (Bundled in port-channel) e non S (Suspended).
show spanning-tree vlan [ID] Mostra chi è il Root Bridge (This bridge is the root), lo stato delle porte (FWD, BLK) e la priorità dello switch.
show cdp neighbors detail Rivela hostname, IP di management, modello hw, e porte usate dall'apparato collegato. Must have se non sai come è cablata la rete.
show ip nat translations Verifica la tabella NAT (es. vedi il mapping Inside Local verso Inside Global).
show access-lists Mostra le righe ACL e il conteggio di quanti pacchetti hanno fatto match su ogni regola.
